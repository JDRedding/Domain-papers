$$


This is the Relation Dynamic Geometry S-mode object: a two-point structural generator.

From this dyad, Relation Dynamic Geometry builds:

- the interaction axis (I-mode)

- the field curvature (Momentum Flux Engine side)

So the quadratic’s free data is exactly the dyad.

### 2. Calculus → function (Relation Dynamic Geometry form)

A calculus system is determined by one free datum:


Relation Dynamic Geometry interprets this as:

- **S-mode:** anchor $a$

In Relation Dynamic Geometry notation:

```text
Relation Dynamic Geometry_Calc = ⟨ a ; f ⟩
```

The anchor $a$ is the Relation Dynamic Geometry reference point; the function $f$ is the behavioral generator.

This matches the claim:

> Calculus to function: free data is the single map $f$.
