# EVOLUTION OF STORAGE DEVICES
From Smallest to Largest  (1950s → 2026)

## FUNDAMENTALS

```
Bit     = 0 or 1
Byte    = 8 bits
KB      = 1,024 bytes
MB      = 1,024 KB
GB      = 1,024 MB
TB      = 1,024 GB
PB      = 1,024 TB
EB      = 1,024 PB
ZB      = 1,024 EB
```

## EARLY ERA
```
Punched Card              ~80 bytes
Paper Tape                Few KB
Magnetic Tape             MBs
8-inch Floppy Disk        80 KB – 1.2 MB
First Hard Disk           5 MB
```

## PC ERA
```
5.25-inch Floppy          360 KB – 1.2 MB
3.5-inch Floppy           1.44 MB
Zip Disk                  100 – 750 MB
CD-ROM                    700 MB
DVD                       4.7 – 8.5 GB
```

## DIGITAL ERA
```
USB Flash Drive           8 MB – 1 TB
SD / microSD Card         16 MB – 1 TB
Blu-ray Disc              25 – 128 GB
External Hard Drive       500 GB – 20 TB
```

## MODERN ERA
```
SSD (SATA)                120 GB – 8 TB
NVMe SSD                  256 GB – 100+ TB
Enterprise Storage        Petabytes
Cloud Storage             Exabytes+
DNA Data Storage          Zettabytes per gram  (experimental)
```

##SCALE
```
Bytes → KB → MB → GB → TB → PB → EB → ZB
```
