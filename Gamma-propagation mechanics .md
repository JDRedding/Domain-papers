# Gamma-propagation mechanics 
Γ-mode in RDGA

Γ is both the mechanism of change (actualization of potency) and, when residual never vanishes, the engine of ongoing relational expansion. Γ is the dynamic-update operator:

Two regimes:
- Classical termination: residual generators reach $\emptyset$, $\dim(I) = \dim_{\rm exp}$, flag Q_OK. Further Γ leaves the configuration invariant (pure-act / unmoved / necessary node).
- Generative / process regime: residual generators remain non-empty for all $n$ (Q_DEGEN persists). Γ continually adjoins new relational capacity. Geometry is the closure of this residual-driven process, not a prior container. 

```
Γ : State_t → State_{t+1}
```

A state consists of:
- primitive objects (with current parameters/coordinates)
- relations among them
- their algebraic carriers $I_R$
- the dependency graph

### Dependency graph
- Nodes = objects and relations
- Edges = “depends on” (directed, essential/here-and-now)

Example: Line $L$ depends on points $A,B$; intersection point $P$ depends on line $L$ and circle $C$.

### Propagation steps (when a primitive changes)
1. Update the changed primitive (e.g., coordinates of $A$).
2. Recompute every derived object that depends on it.
3. Recompute the affected carriers $I_R$.
4. Re-solve the affected systems (elimination, ideal sums, etc.).
5. Push the new solution sets to any attached MFE fields and Q-admissibility checks.

Invariants checked during Γ-updates:
- ideal dimension matches expected dimension (unless degeneracy is allowed)
- Jacobian rank sufficient for a well-posed locus
- arity and tuple structure of relations preserved
- coordinate-free relations (incidence, parallelism, orthogonality, tangency) invariant under admissible transforms

### Residual-driven form
In the generative reading, Γ is residual-driven rather than purely reactive:

```
X_n  := S(R_n)          // current solution set
residual_n := generators of I_{n+1} not redundant in I_n

X_{n+1} = X_n ⊕ Γ(residual_n)
```

What Γ(residual) does:
1. Adjoin new relational tuples generated by the residual generators.
2. Form the new ideal:

$$
I_{n+1} = I_{n} + {residual}_{ideal}
$$

4. Recompute the dependency graph.
5. Eliminate only variables that are fully constrained.
6. Leave excess dimensions as new admissible relations.

# Appendix: Recovery Map and Generator Fibres

The dynamic update operator and the recovery map are distinct but complementary faces of Γ-mode.

## Dynamic Γ vs Recovery Γ

The propagation operator acts on states:

```math
\Gamma_{\mathrm{update}} : \mathrm{State}_t \to \mathrm{State}_{t+1}
```

and governs actualization, dependency propagation, residual elimination, or residual growth.

The recovery map acts on stabilized observables:

```math
\Gamma_{\mathrm{recovery}} : O \to \mathcal{P}(\mathrm{SDI})
```

where:

- $O$ = orbit classes / frozen projections  
- $\mathrm{SDI}$ = stabilized dynamic invariants  

## Projection–Recovery Pair

Let

```math
\Pi : \mathrm{SDI} \to O
```

be the partition-extraction projection that forgets dynamical details and retains only the stabilized relational structure.

The recovery map is a right-inverse on the image:

```math
\Pi \circ \Gamma_{\mathrm{recovery}} = \mathrm{id}_O
```

Thus:

```
Generator
    ↓ Π
Frozen Orbit
    ↑ Γ_recovery
Generator Fibre
```

## Fibre Interpretation

In general:

```math
\Gamma_{\mathrm{recovery}}([\pi]) =
\{
I \in \mathrm{SDI}
:
\Pi(I) = [\pi]
\}
```

possibly restricted to generators of minimal relational complexity.

Because $\Pi$ discards trajectory history, bifurcations, rates, and transient structure:

```
many generators
      ↓
   one orbit
```

Therefore recovery is naturally multi-valued:

```math
\Gamma_{\mathrm{recovery}}([\pi]) \subset \mathrm{SDI}
```

rather than a single generator.

## Relation to Residual Dynamics

For a generator $G$,

```math
\Pi(\mathrm{Attractor}(G)) = [\pi]
```

defines its stabilized projection.

The recovery fibre consists of all admissible generators whose long-time coherence pattern realizes the same orbit:

```math
\Gamma_{\mathrm{recovery}}([\pi]) =
\{
G
:
\Pi(\mathrm{Attractor}(G)) = [\pi]
\}
```

Thus Γ-propagation moves:

```
Generator
 → Attractor
 → Frozen Orbit
```

while Γ-recovery moves:

```
Frozen Orbit
 → Generator Fibre
```

## Role 

The two Γ-operators occupy opposite sides of the same hinge:

```
SDI
   --Π-->
Orbit

Orbit
   --Γ_recovery-->
Fibre(SDI)

State_t
   --Γ_update-->
State_(t+1)
```

- $\Gamma_{\mathrm{update}}$ generates relational structure.  
- $\Gamma_{\mathrm{recovery}}$ reconstructs the family of admissible generators capable of producing a given stabilized relational structure.  

Together they provide the forward and inverse faces of relational dynamics.
