# Gamma-propagation mechanics 
Γ-mode in RDGA

Γ is both the mechanism of change (actualization of potency) and, when residual never vanishes, the engine of ongoing relational expansion. Γ is the dynamic-update operator:

Two regimes:
- Classical termination: residual generators reach $\emptyset$, $\dim(I) = \dim_{\rm exp}$, flag Q_OK. Further Γ leaves the configuration invariant (pure-act / unmoved / necessary node in the Five Ways).
- Generative / process regime: residual generators remain non-empty for all $n$ (Q_DEGEN persists). Γ continually adjoins new relational capacity. Geometry is the closure of this residual-driven process, not a prior container. 

```
Γ : State_t → State_{t+1}
```

A state consists of:
- primitive objects (with current parameters/coordinates)
- relations among them
- their algebraic carriers $I_R$
- the dependency graph

### Dependency graph
- Nodes = objects and relations
- Edges = “depends on” (directed, essential/here-and-now)

Example: Line $L$ depends on points $A,B$; intersection point $P$ depends on line $L$ and circle $C$.

### Propagation steps (when a primitive changes)
1. Update the changed primitive (e.g., coordinates of $A$).
2. Recompute every derived object that depends on it.
3. Recompute the affected carriers $I_R$.
4. Re-solve the affected systems (elimination, ideal sums, etc.).
5. Push the new solution sets to any attached MFE fields and Q-admissibility checks.

Invariants checked during Γ-updates:
- ideal dimension matches expected dimension (unless degeneracy is allowed)
- Jacobian rank sufficient for a well-posed locus
- arity and tuple structure of relations preserved
- coordinate-free relations (incidence, parallelism, orthogonality, tangency) invariant under admissible transforms

### Residual-driven form
In the generative reading, Γ is residual-driven rather than purely reactive:

```
X_n  := S(R_n)          // current solution set
residual_n := generators of I_{n+1} not redundant in I_n

X_{n+1} = X_n ⊕ Γ(residual_n)
```

What Γ(residual) does:
1. Adjoin new relational tuples generated by the residual generators.
2. Form the new ideal:

$$
I_{n+1} = I_{n} + {residual}_{ideal}
$$

4. Recompute the dependency graph.
5. Eliminate only variables that are fully constrained.
6. Leave excess dimensions as new admissible relations.
