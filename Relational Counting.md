# 🧩 Entropy‑quotient counting

RDG treats objects as **relational configurations** inside the SID/PED/Q triads:

- **SID** = Structure, Interaction, Dynamics  
- **PED** = Power, Evaluation, Dynamics  
- **Q‑slice** = moderation of relational evolution

Thus RDG “counting” is:

Don’t count raw nodes.

$$
\text{Count}_{RDG}(X) = |X / \sim_{RDG}|
$$

- information geometry
