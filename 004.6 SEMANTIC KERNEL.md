## Section 1 — RDG Primitive Grammar (Triadic Operator Form)

RDG expresses all relational geometry using a 3-slot operator:

```text
noun_qualifier^dynamic
```

Where:

- **noun** = base entity / structural node  
- **qualifier** = adjective / property / restriction (underscore)  
- **dynamic** = verb / transformation / mode (caret)

This triad is the operational collapse of the RDG 4-seed (point, counterpoint, mirrorpoint, mirror-counterpoint). The seed is 4-fold, but the operator grammar is 3-fold.

**RDG triad = Structure – Interaction – Dynamics.**

## Section 2 — MFE Primitive Grammar (Bipolar Polynomial Form)

MFE expresses all evaluative flux using a bipolar polynomial:

```text
(X⁺ , X⁻)
```

Where:

- \(X^{+}\) = positive pole of concept \(X\)
- \(X^{-}\) = negative pole of concept \(X\)

Flux polynomial:

\[
\Phi(X) = X^{+} - X^{-}
\]

Evaluation:

\[
E(X) = f(\Phi(X))
\]

Q-slice moderation:

\[
Q(X) = \mathrm{moderation}(E(X))
\]

**MFE primitive = bipolar antonym pair + flux + evaluation + Q-slice.**

## Section 3 — RDG/MFE Duality Rule (Semantic Filter)

A concept is a valid primitive **only if**:

1. It has an objective antonym.  
2. The antonym pair forms a stable bipolar flux.  
3. The flux can be evaluated.  
4. The evaluation can be Q-moderated.

If **any** of these fail:

- the concept is **not** a valid RDG primitive  
- the concept is **not** a valid MFE primitive  
- the concept is **not** part of the syntactic keyword set  

This is the RDG–MFE semantic filter.

## Section 5 — Applying the MFE Antonym Filter

Each candidate concept is tested:

- Does it have a clear opposite?  
- Is the opposite objective?  
- Does the pair form a stable polarity?  
- Can the flux be evaluated?  
- Can the evaluation be Q-moderated?

If **yes** → concept survives.  
If **no** → concept is removed.

Typical survival counts:

- NSM: ~20–25 survive  
- WordNet: ~15–20 survive  
- Basic English: ~100–150 survive  

After deduplication: **~120–180 true bipolar primitives remain.**
