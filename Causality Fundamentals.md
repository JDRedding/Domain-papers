## 🧭 **Core Types — Pearl’s Ladder of Causation**
- **Association**  
  $P(Y|X)$: seeing / correlation / prediction  
- **Intervention**  
  $P(Y|do(X))$: doing / action / experiment  
- **Counterfactual**  
  $Y_x$: imagining / “what if” / individual‑level alternate worlds  

The ladder moves from **observation → manipulation → imagination**.

- **Endogenous vs Exogenous** — nodes determined inside vs outside the model

## 🧩 **Graphical Fundamentals**
- **DAG**: Directed Acyclic Graph encoding causal assumptions  
- **Paths**: chains, forks, colliders  
- **d‑separation**: graphical conditional‑independence test  
- **Back‑door criterion**: block all back‑door paths from X → Y  
- **Front‑door criterion**: identify causal effect via mediator  
- **do‑operator**: severs incoming arrows into X (simulated intervention)  

These tools let you compute causal effects from observational data when experiments are impossible.

---

## ⚙️ **Structural Causal Model (SCM)**
A system of deterministic functions + noise:

\[
Y := f_Y(X, U_Y), \qquad X := f_X(U_X)
\]

Each variable is generated by a structural equation.  
The SCM defines **counterfactual worlds**, not just correlations.

---

## 🎯 **Why It Matters**
Pearl’s framework lets us move from:

- **“X is associated with Y”**  
  → correlation / prediction  

to:

- **“If we set X, what happens to Y?”**  
  → intervention / causal effect  

and:

- **“What would Y have been had X been different?”**  
  → counterfactual / individual‑level inference  

This is essential for **robust AI**, **policy evaluation**, **medicine**, **economics**, and any domain where decisions change outcomes.
