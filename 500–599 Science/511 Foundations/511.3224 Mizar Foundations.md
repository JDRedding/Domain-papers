**MIZAR FOUNDATIONS**  
**511.3224 Large cardinals & universes**

The document outlines the foundational choices and style of the Mizar formalization framework: a ZF-style set theory extended with the Tarski–Grothendieck universe, primitive tuple/pair/relation constructions, and a soft-typing, set-based style in which mathematical objects are sets up to extensional equality.

The Tarski–Grothendieck axiom is labeled “stronger” only because it assumes the existence of very large infinite universes. This does not imply superiority; it simply reflects the classical classification of axioms by the infinities they posit.

The foundational stance of this document is that the infinite universes posited by TG are not required for ordinary mathematics and introduce unnecessary ontological commitments. The terminology surrounding them is therefore used only for explanation, not endorsement.

### [1] Foundational Basis
- **Core Logic**: ZF-style set theory  
- **Added Axiom**: Tarski–Grothendieck Universe (TG)  
- **Strength**: ≈ ZFC + inaccessible cardinal  
- Everything is a set; equality is **extensional**:

```
A = B  ⇔  ∀x (x ∈ A ↔ x ∈ B)
```

### [2] Primitive Constructions
- Tuples: primitive objects (not Kuratowski encodings)  
- Ordered pairs: primitive (TARSKI:def 2)  
- Relations: primitive sets of ordered pairs  

Rich relational calculus is available (domain, range, inverse, composition, relational image).  

These refer only to a technical notion used in classical set theory: the existence of larger infinite objects.  
- not “more powerful” in a practical sense  
- not “more expressive” for everyday mathematics  
- not a philosophical ranking of foundations  

### [3] Mizar Style
- Set-theoretic universe  
- Soft typing layer  
- Structures built on extensional equality  
- Mathematical objects = sets with structure  

### [4] Drawbacks and Reasons Not to Use Mizar Foundations
- **Set-only ontology**  
  Everything is a set. No native type theory, no higher-order primitives. Inductive types, dependent types, or polymorphism must be encoded manually as set-structures.

- **Soft typing limitations**  
  Typing is predicate-based and non-coercive. Type errors often surface as failed proofs rather than structural mismatches. Complex structures require many auxiliary registrations.

- **First-order only**  
  No higher-order logic. Quantifying over predicates, functions, or classes requires encodings. This makes some modern mathematics (especially category theory or HoTT-style work) more verbose than in HOL/Coq/Lean.

- **TG axiom strength**  
  Tarski–Grothendieck implies inaccessible cardinals. Users who prefer weaker foundations (pure ZFC, NBG, ETCS, HoTT) may view TG as stronger than necessary for everyday mathematics.

- **Primitive tuples / relations**  
  While convenient, these primitives differ from standard Kuratowski encodings. Porting proofs to other systems often requires translation layers or re-encoding.

- **Legacy infrastructure**  
  Language and tooling are mature but older. Integration with modern proof ecosystems (Lean, Coq, Isabelle) is limited. Automation is intentionally conservative and requires more manual guidance.

- **Category-theoretic friction**  
  Large categories are “small” only relative to a TG universe. Explicit size distinctions (small / large / locally small) become less transparent.

- **Steep learning curve**  
  Soft typing + strict syntax + conservative automation demands detailed justification steps that newer systems frequently automate.

### [5] The “Fallacy of Infinities”
The Tarski–Grothendieck axiom postulates the existence of infinite universes, each corresponding to an inaccessible cardinal. This commits the system to extremely large infinities without mathematical necessity.

**Core objections**:

- **Unnecessary**  
  Most mathematics does not require inaccessible cardinals. TG introduces far more set-theoretic power than typical ZFC developments.

- **Size-obscuring**  
  Treating large categories as “small relative to a universe” hides genuine size distinctions. Some category-theoretic arguments become less transparent.

- **Foundational inflation**  
  TG inflates ontology: instead of proving existence of large structures, the axiom grants them wholesale.  
  An axiom is called *stronger* when it asserts the existence of more expansive infinite sets (e.g., inaccessible cardinals). This is a statement about consistency strength, not usefulness.  
  An axiom is called *weaker* when it commits to fewer or smaller infinite sets. It does not imply inferiority or practical limits; it simply avoids assuming certain large infinities.

- **Philosophical skepticism**  
  Grothendieck universes are viewed by some as a convenience axiom rather than a principled foundation—assuming huge sets exist simply because they make category theory tidy.

- **Portability cost**  
  Formalizations that rely on TG may not translate directly to weaker systems (ZFC, NBG, ETCS, HoTT), requiring re-engineering of size arguments.
