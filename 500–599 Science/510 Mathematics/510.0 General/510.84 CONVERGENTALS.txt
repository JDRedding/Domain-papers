                        CONVERGENTALS                          
                 (Fractal-Origin Convergent Form)              
+---------------------------------------------------------------+
510.84 — Advanced Mathematical Structures

Summary
This document defines Convergentals, a recursive geometric object
with embedding S, invariants G, operator Φ, and step scale D.
Both infinities are cut: extent by R_max, descent by ε.

Core Concept
Convergentals begin at a micro seed, take fractal injection in a
meso band, and stop at a finite truncation:
	r = R_max  and  ρ = ρ_★  and  λ_min = ε
One operator:
	S_{t+1} = Φ(S_t, G)

Key Components
The Four Channels:
- G (Geometry): knot class, R_max, ε, ρ_★. Not the current embedding.
- S (Structure): current embedding. Matches G only at the fixed point.
- I (Interaction): Φ. g_f seeds the meso band. g_out holds the
	envelope. g_in holds detail at ρ_★.
- D (Dynamics): step scale inside Φ. Small near R_max.

The Dual-Engine Operator Φ
Outbound finishes the macro infinity. Inbound finishes the micro.
1. F_frac / F_micro: insert only at feature length ≥ ε.
	g_in = max(0, ρ_★ - ρ) restores detail. Zero at ρ_★.
2. F_macro: curvature above ε, radius toward R_max, topology held.
	g_out = (r / R_max)^p
D multiplies the step. Π_ε clips ||x|| > R_max and rejects
insertions shorter than ε.

Scale Behavior
| Scale 		| Zone 			| Behavior
|-------		|------			|----------
| Micro 		| λ = ε 		| Descent stopped
| Meso 			| ε < λ < R_max 	| Fractal held at ρ_★
| Macro 		| r → R_max 	| Envelope held by g_out

Distinctive Properties
- Fractal-origin expansion
- Finite radius (R_max) and finite depth (ε)
- Detail invariant ρ_★, not smoothed to zero
- Knot-compatible (trefoils, braids, torus knots)
- Reject on crossing change and on feature length < ε
- Fixed point: r = R_max and ρ = ρ_★

+---------------------------------------------------------------+

DEFINITION:
  A Convergental is a geometry-aware recursive object. S is the
  current embedding. G is the target invariants. I is the operator
  Φ. D is the step scale inside Φ. The object begins at a micro
  seed, takes fractal injection in the meso band, and converges
  at R_max to a fixed point Φ(S, G) = S.   
  Both infinities are cut: r → R_max and detail descent → ε.
  Converged form keeps ρ_★, the fractal stopped at ε.
  single symbolic operator: S_{t+1} = Φ(S_t, G)

+---------------------------------------------------------------+
|                    FINITE FRACTAL BOUNDS                      |
+---------------------------------------------------------------+
Two infinities, two cuts:
  macro infinity : extent  → cut by R_max
  micro infinity : descent → cut by ε
ε is the smallest feature length stored in G.
  0 < ε < α R_max
Generation cap from the two cuts:
  N_max = floor( log(R_max / ε) / log(1/s) )
  s = contraction ratio of F_frac, 0 < s < 1
Detail invariant, not zero:
  ρ(S)  = feature count at scales ≥ ε
  ρ_★   = ρ of the fractal stopped at ε
Fixed point is both cuts:
  r = R_max  and  ρ(S) = ρ_★  and  λ_min(S) = ε
A smooth knot with ρ = 0 is not the converged object.

+---------------------------------------------------------------+
|                      CONVERGENTALS STEP                       |
+---------------------------------------------------------------+
Inputs:
  S_t      : current structure
  G        : R_max, ε, ρ_★, knot class
  α        : meso threshold (0 < α < 1)
  p        : flow exponent (p ≥ 1)
  k_c, k_r, k_t
Derived:
  r_t      = max_i ||S_t[i]||
  ρ        = detail at scales ≥ ε
  g_f      = 1_{r_t < α R_max} * max(0, 1 - r_t / (α R_max))
  g_out    = (r_t / R_max)^p
  g_in     = max(0, ρ_★ - ρ)
  D_t      = 1 / (1 + exp(5 * (r_t / R_max - 0.9)))
Flows:
  F_frac   = FractalPerturb(S_t)          ; reject if length < ε
  F_macro  = FlowTowardG(S_t, G)          ; curvature only above ε
  F_micro  = DetailRestore(S_t, ρ_★, ε)   ; zero at ρ_★
Update rule:
  S_{t+1} =
      Π_ε( S_t
           + D_t * ( g_f * F_frac
                     + g_out * F_macro
                     + g_in * F_micro ) )
Clip:
  reject insertion if feature length < ε
  for each point x:
      if ||x|| > R_max: x = x * (R_max / ||x||)
Outputs:
  S_{t+1}, D_t
-----------------------------------------------------------------
def ConvergentalsStep(S, G, R_max=1.0, eps=0.02, rho_star=8.0,
                      alpha=0.6, p=2.0, k_c=0.05, k_r=0.1, k_t=0.02):
    r = np.linalg.norm(S, axis=1).max()
    rho = Detail(S, eps)
    g_f = max(0.0, 1.0 - r / (alpha * R_max)) if r < alpha * R_max else 0.0
    g_out = (r / R_max) ** p
    g_in = max(0.0, rho_star - rho)
    D = 1.0 / (1.0 + np.exp(5.0 * (r / R_max - 0.9)))
    if g_f > 0.0:
        S = S + D * g_f * FractalPerturb(S, eps)
    S = S + D * g_out * FlowTowardG(S, G, k_c, k_r, k_t, eps)
    if g_in > 0.0:
        S = S + D * g_in * DetailRestore(S, rho_star, eps)
    norms = np.linalg.norm(S, axis=1)
    over = norms > R_max
    S[over] *= (R_max / norms[over])[:, None]
    return S, D

+---------------------------------------------------------------+
|              FlowTowardG — concise definition                 |
+---------------------------------------------------------------+

Operator decomposition
-
FlowTowardG is composed of three sub-flows:
    FlowTowardG = CurvatureFlow
                + RadiusFlow
                + TopologyFlow
Each one is geometry-aware.

CurvatureFlow(S, G)
-
    curvature_term = -k_c * (Curvature(S) - Curvature(G))
    curvature_term[feature_length(S) <= eps] = 0

RadiusFlow(S, G)
-
r = max_i ||S[i]||, not a per-point radius.
    RadiusFlow = -k_r * (r - R_max) * u(S)
u(S) = outward unit radial field.
Meaning:
    inside radius → outward push
    at radius → no effect
    beyond radius → inward pull
The per-point clip is the backstop, not this flow.

TopologyFlow(S, G)
-
Preserves knot invariants:
    TopologyFlow = -k_t * TopologicalDeviation(S, G)
Where TopologicalDeviation measures:
    crossing number drift
    braid word drift
    linking number drift
    writhe deviation
Reject the step if crossing number or braid-word length changes.

---

Full operator
-
FlowTowardG(S, G) moves S toward the invariants in G.
function FlowTowardG(S, G):
    r = max_i ||S[i]||
    curvature_term = -k_c * (Curvature(S) - Curvature(G))
         curvature_term[feature_length(S) <= eps] = 0
    radius_term = -k_r * (r - R_max) * u(S)
    topology_term = -k_t * TopologicalDeviation(S, G)
    return curvature_term
         + radius_term
         + topology_term
