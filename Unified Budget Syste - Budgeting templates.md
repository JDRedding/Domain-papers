# **Unified Budget System (UBS v1.0)**  
- Budgeting Templates
Full ecosystem 

A unified budget system works by running **four synchronized layers** — Daily → Weekly → Monthly → Yearly — all feeding a single master ledger. Specialized budgets (projects, holidays, savings goals) plug into the same structure using modular sub‑ledgers. Everything rolls up into one dashboard.

A unified budget system is one framework that handles **daily**, **weekly**, **monthly**, **yearly**, and **special‑purpose** budgeting without switching templates or workflows. Below is a complete, structured system built in ASCII‑clean form, with clear operators, flows, and category logic. 

---

## **System Architecture**
The UBS has **five modules**, each with a defined role:

```
[ DAILY ] → [ WEEKLY ] → [ MONTHLY ] → [ YEARLY ] → [ MASTER LEDGER ]
      \           \            \             \             /
       \           \            \             \           /
        -----------[ SPECIALIZED MODULES ]---------------
```

Each module is independent but synchronized through shared categories.

## **Workflow (How the System Runs)**
- A **single unified budgeting system**
1. **Daily logs** capture micro‑transactions.  
2. **Weekly sheets** aggregate daily logs and enforce envelopes.  
3. **Monthly planners** analyze performance and generate KPIs.  
4. **Yearly maps** forecast long‑term trends.  
5. **Master ledger** unifies everything into one dashboard.

This creates a single coherent system instead of scattered templates.

Manage **every scale of budgeting** 

- daily, weekly, monthly, yearly, and goal‑specific 

## **🛠 How to Use These Templates**
— using customizable templates

- **Select Your Format**  
  Choose **PDF** for pen‑and‑paper or **Google Sheets/Excel** for automatic calculations.

- **Customize Categories**  
  Tailor **income**, **expenses**, and **savings** to your lifestyle or project.

- **Track Regularly**  
  Log **daily transactions**, **weekly totals**, and **monthly summaries**.

- **Set Goals & Limits**  
  Use built‑in fields for **spending caps**, **savings targets**, and **project budgets**.

- **Analyze Trends**  
  Graphs and summaries help you spot patterns and optimize spending.

Each template type supports category customization, regular tracking, and visual summaries to help you analyze trends and stay aligned with financial goals.

## **Core Categories (Unified Across All Modules)**

- **Income**  
  Wages, freelance, transfers, refunds, passive income.

- **Fixed Expenses**  
  Rent, utilities, insurance, subscriptions.

- **Variable Expenses**  
  Food, transport, discretionary, household.

- **Debt**  
  Minimums, extra payments, interest.

- **Savings**  
  Emergency fund, sinking funds, long‑term goals.

- **Projects**  
  Materials, labor, milestones, variances.

- **Special Events**  
  Holidays, travel, birthdays, seasonal spending.

These categories appear in every module so the system stays unified.

## 📅 **Daily & Weekly Budgets**
Daily and weekly templates help you track short‑cycle spending and income allocation.

### **Daily Budget Templates**
- **Daily logs** from Monday–Sunday  
- **Spending‑by‑category** lists  
- **Budget vs actual** totals  
- Ideal for **cash envelope systems** and quick check‑ins

### **Weekly Budget Templates**
- **Weekly income tracking**  
- **Customizable categories** for bills, debts, expenses  
- Styles range from **aesthetic/cute** to **professional/structural**  
- All formats support **printable** and **editable** versions
