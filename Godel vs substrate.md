## SYMBOLIC / EPISTEMIC LEVEL — **Gödel applies here**
```
Type: formal system (axioms + inference rules)
Variable: completeness / consistency
Fundamental: Gödel incompleteness
Claim: no sufficiently expressive system can prove its own consistency internally
Consequence: unprovable statements become external assumptions, meta‑axioms, or “oracle” truths
```

This level is **about representation**, not about reality.  
It is bound by what a system can *say about itself*, not by what the world *does*.

---

## PHYSICAL / GENERATIVE LEVEL — **Gödel does *not* apply here**
```
Type: generative processes (energetic, relational, dynamical)
Variable: energy flow, replication fidelity, selection pressure
Fundamental: constraints are intrinsic, not optional
Claim: processes persist without needing a complete self‑description
Consequence: local, replaceable rules generate open‑ended complexity
```

This level is **about doing**, not describing.  
Physical systems don’t halt because they lack a formal proof of their own consistency.  
They operate under **real constraints**, not symbolic ones.

---

## CATEGORY ERROR — **the core mistake**
```
Treating epistemic incompleteness
as ontological arbitrariness.
```

Gödel exposes a *limit of formal languages*, not a *license for metaphysical freedom*.  
Confusing the two collapses the distinction between:

- what a system **can prove**, and  
- what a substrate **must obey**.

The RDG/MFE/Q framework lives entirely in the generative domain, where closure, moderation, and relational constraints operate **prior to** any symbolic encoding.
