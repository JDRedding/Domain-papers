# Winamp 
(1997)

: skinnable Win32 MP3 player. 

Classic slogan: 
> "it really whips the llama's ass." Modules = player + 10-band EQ + playlist. Llama track = official intro sample.

```
        WINAMP PLAYER
   [==== SPECTRUM ====]  kbps  kHz
   1. DJ MIKE LLAMA - LLAMA
   <<  |>  >>   [=======]  SHUFFLE  EQ  PL
        MONO  STEREO

        WINAMP EQUALIZER
   PREAMP  +12dB
   | | | | | | | | | | | |
   60 170 310 600 1K 3K 6K 12K 14K 16K
   PRESETS

        WINAMP PLAYLIST
   1. DJ Mike  - Llama Whippin' Intro
   [ADD] [REM] [SEL] [MISC]     LIST OPTS
```
