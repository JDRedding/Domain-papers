# NEWTON SPECTRUM AS DORIAN MONOCHORD

Undifferentiated white light  ->  prism  ->  colored ribbon 
treated as a single string (monochord) fretted at just-intonation 
string-length ratios that occupy one octave.

## STRING LENGTH L   
inverse to frequency
```
L = 1      Red      (longest span, lowest f)
L = 8/9    Orange   (half-step location)
L = 5/6    Yellow
L = 3/4    Green
L = 2/3    Blue
L = 3/5    Indigo   (half-step location)
L = 9/16   Violet
L = 1/2    (octave, shortest visible span)
```
## VARIABLES & RELATIONS
```
  L_string  ∝  λ_light          (longer string = longer wavelength)
  f         =  1 / L            (string) 
  f_light   =  c / λ
  λ_red / λ_violet  ≈  7/4     (≈ 700 nm / 400 nm)
```
## SCALE FACT
The arithmetic series itself does not stop at the eye.

Seven named hues occupy the seven intervals of a Dorian scale.
```
Orange and indigo sit at the two half-steps.
The visible band is only the middle octave:
  heat rays continue below red
  chemical (UV) rays continue above violet
```
