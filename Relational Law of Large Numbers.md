# Law of Large Numbers
The formulation isolates the three classical ingredients:

```text
S:
    state space with a fixed invariant measure

I:
    accumulation of independent samples

D:
    convergence of the empirical mean
    toward the expectation
```

No probabilistic content is lost. The language simply provides an explicit decomposition into:

```text
Structure
Interaction
Dynamics
```

of the classical Law of Large Numbers.


## Core Correspondence

### Structure (S)

```text
S = (X, R, N)

X = {0,1}
    admissible states

R : Trial -> X
    outcome relation

P(R = 1) = 1/2
P(R = 0) = 1/2

N ∈ ℕ
    interaction count
```

### Interaction (I)

```text
I = M(N)

             N
M(N) = (1/N) Σ R(i)
            i=1

M* = E[R] = 1/2
```

where:

```text
M(N) = observed relational balance
M*   = equilibrium relation
```

### Dynamics (D)

```text
D = {M(1), M(2), M(3), ...}

M(N+1)
=
[N·M(N) + R(N+1)] / (N+1)
```

The dynamics are generated by the sequential accumulation of outcomes.

---

## Weak Law of Large Numbers

For every ε > 0,

```text
Pr(|M(N) - M*| > ε) -> 0
```

as

```text
N -> *
```

### Interpretation

As the number of interactions increases, th* probability of observing a substa*tial deviation from the equilibriu* relation approaches zero.

---

## Strong Law of Large Numbers

```text
Pr(
    lim M(N) = M*
    N->∞
) = 1
```

### Interpretation

With probability one, the observed relational balance converges to the equilibrium relation.

---

## Fluctuation Scale

For a fair Bernoulli process,

```text
δ(N) = 1/(2√N)
```

where

```text
δ(N)
```

is the characteristic relational fluctuation scale.

This is identical to the classical standard error of the sample mean.

---

## Absolute vs. Relative Imbalance

Define the absolute imbalance:

```text
B(N) := |2H(N) - N|
```

where

```text
H(N)
```

is the cumulative number of heads.

Typically,

```text
B(N) ~ O(√N)
```

so the absolute imbalance grows with increasing interaction count.

However,

```text
M(N) - M*
=
B(N)/(2N)
```

and therefore typically

```text
M(N) - M*
~
O(1/√N)
```

so the relative imbalance shrinks.

### Key Distinction

```text
Absolute imbalance:
    grows like √N

Relative imbalance:
    shrinks like 1/√N
```

This is the classical distinction between a growing raw count difference and a vanishing proportional difference.

In Relational Dynamic Geometry language:

> Local relational noise accumulates, while global relational structure stabilizes.
