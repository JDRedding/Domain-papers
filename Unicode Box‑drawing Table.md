# *Full* Unicode Box‑drawing Table 
Unicode block coverage

The entire block spans: U+2500 – U+257F

# **1. Single‑line box drawing**
### **Corners**
```
┌  U+250C   top-left
┐  U+2510   top-right
└  U+2514   bottom-left
┘  U+2518   bottom-right
```

### **Tees**
```
┬  U+252C   top tee
├  U+251C   left tee
┤  U+2524   right tee
┴  U+2534   bottom tee
┼  U+253C   cross
```

### **Lines**
```
─  U+2500   horizontal
│  U+2502   vertical
```

# **4. Mixed single/double connectors**
These exist so you can join single‑line boxes to double‑line boxes.

```
╒  U+2552   single top-left, double horizontal
╓  U+2553   double vertical, single horizontal
╔  U+2554   double both
╕  U+2555   single top-right, double horizontal
╖  U+2556   double vertical, single horizontal
╗  U+2557   double both
```

```
╘  U+2558   single bottom-left, double horizontal

╚  U+255A   double both
╛  U+255B   single bottom-right, double horizontal
╜  U+255C   double vertical, single horizontal
╝  U+255D   double both
```

```
╞  U+255E   single left tee, double horizontal
```

# **5. Light/Heavy mixed connectors**
These are used in advanced TUI layouts:

```
┍ ┎ ┏   top-left variants
┑ ┒ ┓   top-right variants
┕ ┖ ┗   bottom-left variants
┙ ┚ ┛   bottom-right variants
```

```
┯ ┰ ┳   top tees
┠ ┡ ┢ ┣   left tees
┨ ┩ ┪ ┫   right tees
┷ ┸ ┹ ┻   bottom tees
╀ ╁ ╂ ╃ ╄ ╅ ╆ ╇ ╈ ╉ ╊ ╋   mixed crosses
```
