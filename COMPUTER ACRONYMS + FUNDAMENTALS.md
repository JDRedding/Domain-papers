# COMPUTER ACRONYMS + FUNDAMENTALS

## HARDWARE / PROCESSING
```
CPU   Central Processing Unit          Executes instructions; the computer's brain
GPU   Graphics Processing Unit         Handles graphics, video, and parallel compute
SMPS  Switched-Mode Power Supply       Converts AC wall power to DC for components
DPI   Dots Per Inch                    Print/screen resolution density
```
## MEMORY
```
RAM   Random Access Memory             Fast volatile working memory (lost on power-off)
ROM   Read Only Memory                 Permanent firmware storage (BIOS/UEFI)
```
## STORAGE
```
HDD   Hard Disk Drive                  Magnetic spinning-disk storage
SSD   Solid State Drive                Fast flash storage with no moving parts
USB   Universal Serial Bus             Hot-plug interface for peripherals and storage
```
## NETWORKING
```
IP    Internet Protocol                Addressing system for devices on a network
LAN   Local Area Network               Network inside one building or site
WAN   Wide Area Network                Network spanning cities or countries
Wi-Fi Wireless Fidelity                Wireless local networking (IEEE 802.11)
VPN   Virtual Private Network          Encrypted tunnel over a public network
HTTP  HyperText Transfer Protocol      Protocol for fetching web pages
HTTPS HyperText Transfer Protocol Secure  HTTP + TLS encryption
```
## WEB / DATA / FILES
```
HTML  HyperText Markup Language        Structure and markup of web pages
PDF   Portable Document Format         Fixed-layout document format
SQL   Structured Query Language        Language for querying relational databases
```
