# Relational Frobenius 
**Bourbaki theory**

Everything required by classical finite-field Frobenius is expressed using only the native Relational-Bourbaki primitives:

- regions (carriers),
- structure patterns (modular adjacency),
- interaction relations (the map $F$),
- flux iteration (dynamics),
- flux-orbit and flux-stable subregions (species).

The Galois action is thereby reduced to pure moderated flux on a modular region. No additional ontology is needed.

### 1. Multiplicative group as region
Region $G$:
- Nodes = residues $j\in\mathbb{Z}/(q-1)$
- Structure pattern = modular addition (the clock adjacency)
- Interaction pattern = the single-valued relation $F$ defined by
  \[
  (j,\,pj)\in F
  \]
- Dynamics = flux generated by iteration of $F$

This is the Structure–Interaction–Dynamics triad applied directly to the exponent clock.

### 2. Frobenius as function-relation
$F$ is a total function-relation on $G$:
- Exactly one outgoing edge from every node
- Edge target is ordinary multiplication by the integer $p$ modulo $q-1$

Flux is simply repeated application:

$$
j\;\xrightarrow{F}\;pj\;\xrightarrow{F}\;p^2j\;\xrightarrow{F}\;\dots
$$

### 3. Cyclotomic cosets as flux-orbit regions
For each starting node $j$ the flux-orbit region is the subregion
```
OrbitRegion(j) =
  Nodes     = { pⁿ·j mod (q-1) | n ≥ 0 }
  Structure = restriction of modular addition
  Interaction = restriction of F
  Dynamics  = closed flux (eventually periodic)
```
These subregions partition $G$.

### 4. Period = dynamic closure degree
The length of OrbitRegion($j$) is the period of the flux:

$$
\{Period}(j)=\min\{d>0:F^d(j)=j\}.
$$

Every such period divides $k$.

### 5. Fixed (gold) nodes and the prime-field region
Nodes satisfying $F(j)=j$ form the fixed region
```
FixedRegion =
  Nodes     = { j | (p-1)j ≡ 0 mod (q-1) }
  Interaction = identity self-loops
  Dynamics  = trivial (zero) flux
```
Cardinality $p-1$; it is the image of $\mathbb{F}_p^\times$ under discrete log.

### 6. Subfields as flux-stable species
A subfield of degree $d\mid k$ appears as the flux-stable region
```
SubfieldRegion(d) =
  Nodes     = union of all OrbitRegions of period exactly d
            (plus FixedRegion when appropriate)
  Structure = inherited modular structure
  Interaction = F restricted to these nodes
  Dynamics  = flux cycles of uniform period d
```
Its node count is $p^d-1$. The collection of all such regions realises the subfield lattice as a lattice of flux-stable species.

### 7. The three concrete regions

**Region size 7 ($p=2$)**  
Interaction $j\to 2j\bmod 7$  
- FixedRegion = $\{0\}$  
- Two OrbitRegions of period 3: $\{1,2,4\}$, $\{3,6,5\}$  
→ single nontrivial species of degree 3.

**Region size 8 ($p=3$)**  
Interaction $j\to 3j\bmod 8$  
- FixedRegion = $\{0,4\}$  
- Three OrbitRegions of period 2  
→ quadratic species of degree 2.

**Region size 15 ($p=2$)**  
Interaction $j\to 2j\bmod 15$  
- FixedRegion = $\{0\}$  
- One OrbitRegion of period 2: $\{5,10\}$  
- Three OrbitRegions of period 4  
→ species of degrees 1, 2 and 4.
