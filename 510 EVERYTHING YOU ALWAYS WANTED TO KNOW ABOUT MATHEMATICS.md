## 🧭 **What Mathematics Actually Is**
Mathematics is not calculation.  
It is the art of:

- inventing precise statements,  
- deciding whether they are true, and  
- writing arguments that **force agreement** from any rational observer.

A statement is true only when it can be shown to hold **always**, not just in examples.

---

# **Number Types (Sets of Numbers)**

- **ℕ** — naturals: {0, 1, 2, 3, …}  
- **ℤ** — integers: {…, −2, −1, 0, 1, 2, …}  
- **ℚ** — rationals: \(p/q\) with \(p,q∈ℤ, q≠0\)  
- **ℝ** — reals: limits of rationals (includes √2, π, e)  
- **ℂ** — complex: \(a+bi\), \(a,b∈ℝ\)

---

# **Common Variables**
- **n, m, k, i, j** — usually naturals or integers  
- **x, y, z** — usually real numbers  
- **p, q** — primes or rationals  
- **f, g, h** — functions  
- **A, B, S, T** — sets  
- **P(n)** — a statement depending on n  
- **ε, δ** — small positive reals (analysis)

---

# **Set Fundamentals**

- **x ∈ A** — x is an element of A  
- **A ⊆ B** — A is a subset of B  
- **A = B** — same elements  
- **∅** — empty set  
- **A ∪ B** — union (or)  
- **A ∩ B** — intersection (and)  
- **A \ B** — difference  
- **P(A)** — power set  
- **|A|** — cardinality (size)

---

# **Basic Logical Connectives**

- **P ∧ Q** — and  
- **P ∨ Q** — or  
- **¬P** — not  
- **P → Q** — implies  
- **P ↔ Q** — iff  
- **∀x** — for all  
- **∃x** — there exists

---

# **Core Proof Techniques**

- **Direct proof** — assume P, derive Q  
- **Contradiction** — assume P and ¬Q, reach absurdity  
- **Contrapositive** — prove ¬Q → ¬P  
- **Induction** — base case + step  
- **Cases** — split into exhaustive scenarios  
- **Construction** — exhibit the required object

These are the “moves” learned to wield fluently.

# **Quick Classic Facts the Book Walks Through**

- **Triangle angles sum to 180°** — requires proof, not a picture  
- **Infinitely many primes** — Euclid  
- **√2 is irrational**  
- **Sum of first n positives** = \(n(n+1)/2\)  
- **Monty Hall** — switching wins with probability 2/3  
- Polynomials, binomial coefficients, pigeonhole principle, bijections
