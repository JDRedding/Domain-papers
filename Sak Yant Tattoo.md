# **Sak Yant Tattoo Breakdown — Angelina Jolie**  
Artist: **Ajarn Noo Kanpai**  
Type: **Traditional Thai Sacred Tattoo (Sak Yant)**  
Top text: **“Know your rights”** — reference to *The Clash*

---

## **LeftSide — Hah Taew (Five‑Line Blessing)**  
```
struct LeftSide {
    type: HahTaew;           // 5-line blessing
    script: Khmer;
    purpose: "Protection for Angelina and son Maddox";
    lines: [
        "May your enemies run far away from you",
        "If you acquire riches, may they remain yours always",
        "Your beauty will be that of Apsara",
        "Wherever you go, many will attend, serve and protect you"
    ];
}
```

The **Hah Taew** is one of the most iconic Sak Yant designs, traditionally granting protection, charisma, and good fortune.

## **RightSide — Yant Kraw Petch (Diamond Armor)**  
```
struct RightSide {
    type: YantKrawPetch;     // Diamond Armor
    benefits: [
        "luck",
        "virtue",
        "wealth",
        "success",
        "protection from failure"
    ];
}
```

The **Diamond Armor Yant** symbolizes invulnerability, resilience, and amplified good fortune.

---

## **Center — Yant Phutson**  
```
struct Center {
    type: YantPhutson;
    purpose: "Mercy and fortune";
    extras: "grids representing the four elements and continents";
}
```

**Yant Phutson** is associated with compassion, blessings, and balanced fortune. The grid motifs represent classical cosmology — elements and continents as stabilizing symbolic anchors.
