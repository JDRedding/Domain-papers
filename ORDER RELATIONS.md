# ORDER RELATIONS
## Foundations

- Binary relation $R$ on a set $X$
- **Preorder:** reflexive + transitive
- **Partial order (poset):** antisymmetric preorder  
  (strict version: irreflexive + transitive)

---

## 1. Order Relations (strict form)

A **strict order** is:

- **irreflexive:** $\neg(x < x)$
- **transitive:** $x < y < z \Rightarrow x < z$
- **asymmetric** follows automatically

Refinements of the same binary relation:

- **Total order** — trichotomy: $x < y \lor x = y \lor y < x$
- **Well-founded** — no infinite descending chains
- **Dense** — between $x < y$ there exists $z$
- **Unique successors** — each $x$ has a single immediate successor $y$
- **Well-ordered** — total + well-founded

## 2. Lattice Theory (order → algebra)

Given a poset $(P,\le)$:

- **meet** $a \wedge b$ = greatest lower bound
- **join** $a \vee b$ = least upper bound

Structural upgrades:

- **Semilattice** — only $\wedge$ or only $\vee$ exists for pairs
- **Lattice** — both exist for all pairs
- **Bounded lattice** — has $0$ and $1$
- **Complete lattice** — all subsets have inf/sup
- **Distributive** — $\wedge$ distributes over $\vee$
- **Modular** — weaker distributivity: $a \le c \Rightarrow a \vee (b \wedge c) = (a \vee b) \wedge c$
- **Boolean algebra** — bounded distributive complemented lattice
- **Heyting algebra** — bounded lattice with relative pseudocomplement (intuitionistic implication)

Canonical examples:

- power set $(\subseteq,\cap,\cup)$ — complete Boolean
- subspaces of a vector space — modular
- open sets of a space — complete Heyting (frame)

```
Poset (P, ≤)

  Meet a ∧ b  = greatest lower bound (inf)
  Join a ∨ b  = least upper bound (sup)

  Semilattice
    meet-semilattice: every pair has a ∧ b
    join-semilattice: every pair has a ∨ b

  Lattice
    every pair has both meet and join
    equivalently: ∧, ∨ commutative, associative, idempotent
    + absorption: a ∨ (a ∧ b) = a

  Bounded lattice      0 (bottom) and 1 (top)
  Complete lattice     every subset has inf and sup
  Distributive         a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)
  Modular              a ≤ c  ⇒  a ∨ (b ∧ c) = (a ∨ b) ∧ c
  Boolean algebra      bounded distributive complemented
  Heyting algebra      relative pseudocomplement
```

## 3. Topology (order → topology → order)

### 3.1 Order topology (total orders)

Subbasis:

- $\{ x \mid x < a \}$
- $\{ x \mid a < x \}$

On $\mathbb{R}$ this recovers the usual topology.

- connected $\Leftrightarrow$ Dedekind-complete
- compact $\Leftrightarrow$ complete + bounded

### 3.2 Alexandrov topology (any preorder)

Open sets = **upper sets**.  
Finest topology whose specialization preorder recovers the original relation.

### 3.3 Specialization preorder (any topology)

$$
x \le y \iff x \in \overline{\{y\}}
$$

- $T_0$ $\Leftrightarrow$ antisymmetric specialization
- $T_1$ $\Leftrightarrow$ specialization is equality

### 3.4 Scott topology (dcpos / complete lattices)

Open sets are upper sets inaccessible by directed sups.  
Core of domain theory.

### 3.5 Lower / upper topologies

Generated by principal down-sets or up-sets.  
Coarser than Alexandrov / order topologies.

### 3.6 Structural links

- lattices of open sets → frames / locales
- continuous lattices ↔ injective spaces
- well-orders ↔ discrete / successor topology
- dense total orders ↔ no isolated points

```
Order topology (total order)
  subbasis: { x | x < a }  and  { x | a < x }
  connected ⇔ Dedekind-complete
  compact   ⇔ complete + bounded

Alexandrov topology (preorder)
  open sets = upper sets
  finest topology with given specialization preorder

Specialization preorder of a topology
  x ≤ y  ⇔  x ∈ cl{y}
  T₀ ⇔ antisymmetric
  T₁ ⇔ discrete order (equality)

Scott topology (dcpo / complete lattice)
  upper sets inaccessible by directed sups

Lower / upper topology
  principal down-sets or up-sets
```

## 4. The Cycle

Orders generate topologies; topologies regenerate orders. When the constructions are compatible, the loop is idempotent.

$$
\text{preorder } R
\;\longrightarrow\;
\text{Alexandrov topology } \mathcal{A}(R)
\;\longrightarrow\;
\text{specialization preorder } R
$$

$$
\text{complete lattice } L
\;\longrightarrow\;
\text{Scott topology } \sigma(L)
\;\longrightarrow\;
\text{specialization order } \le_\sigma
$$

$$
\text{total order } <
\;\longrightarrow\;
\text{order topology } \tau(<)
\;\longrightarrow\;
\text{specialization order induced by } \tau
$$

**Orders generate lattices of opens; lattices generate topologies; topologies regenerate orders.**
